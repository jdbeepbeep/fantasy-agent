This is a personal, non-commercial project built by an individual to monitor their own fantasy football leagues (injuries, waivers, trades) and send SMS alerts to their own phone number.

Message program description

This program sends text alerts about fantasy football roster events (player injuries, suggested waiver moves, trade evaluations) to a single recipient: the tool's own owner.

Message frequency

Message frequency varies based on real-world sports events -- typically a few messages per day during the football season, and rarely or never outside of it.

Costs

Standard message and data rates may apply, per the recipient's own mobile carrier plan.

Opt-out

Reply STOP at any time to stop receiving messages.

Help

Reply HELP for assistance, or contact the tool owner directly.
